# Letter For ELL ✨

Surat web interaktif spesial dan romantis untuk Natasha Stella Vika.

## 🌐 Live Preview
- **URL**: [https://v0rade.github.io/Letter-For-ELL/](https://v0rade.github.io/Letter-For-ELL/)

## ✨ Fitur & Perbaikan
- **Entrypoint**: Menyediakan `index.html` dan `dfolt.html` agar kompatibel dengan GitHub Pages, Vercel, dan Netlify.
- **Self-contained Assets**: Gambar, stiker panda cinta, wallpaper, audio MP3, serta pustaka TypeIt disimpan secara lokal di folder `assets/` agar tidak bergantung pada server luar yang rentan down.
- **Audio Autoplay & Fallback**: Memastikan musik latar otomatis terpicu secara mulus saat tombol awal ditekan atau saat surat dibuka.
- **Perbaikan Animasi Ketik (TypeIt)**: Menghapus scrolling agresif berulang yang mengganggu, menyesuaikan autoscroll halus mengikuti teks baru, dan memperbaiki pemisah baris pesan.
- **Desain Responsif**: Tampilan tetap rapi dan nyaman dibaca baik di layar PC mau pun ponsel (smartphone).
